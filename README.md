# 부스 배치 시뮬레이터 (수업나눔페스타)

전시 부스를 **실제 크기(cm)** 로 3D에 배치해 보는 웹 도구입니다.
설치나 빌드 없이 `index.html` 을 열면 바로 동작합니다.

## 실행 방법

| 방법 | 설명 |
| --- | --- |
| Vercel (권장) | 클라우드 저장·공유 링크까지 사용. 아래 "클라우드 저장" 설정 참고 |
| 더블클릭 | 폴더째 내려받아 `index.html` 을 더블클릭 (인터넷 연결 필요: three.js 를 CDN에서 불러옴). 저장은 브라우저 자동저장과 JSON 파일로 |
| GitHub Pages | 저장소 Settings → Pages → 브랜치 선택. 서버 코드를 못 돌리므로 클라우드 저장은 Vercel API 주소를 따로 지정해야 함 |
| 구글 사이트 | 배포된 주소를 **삽입 → URL로 삽입** 하세요. ("코드 삽입"은 css/js 파일을 못 찾으므로 URL 방식 권장) |

처음 열면 **부스 형태(ㄷ자·ㅡ자·ㄴ자·독립형 섬·칸막이 패널형)와 크기**를 고르는 창이 뜹니다.
"예시 배치 넣기"를 켜 두면 300×300 ㄷ자 부스, 뒷벽의 연구학교 5개교 현수막(2열×3행, 칸당 100×70cm),
테이블 2개, 의자 4개가 놓인 데모 장면으로 시작합니다.

## 클라우드 저장 (MongoDB) — Vercel 배포

- 처음 접속하면 가운데는 빈 화면이고, 왼쪽 위 **[새로 시작] / [불러오기]** 로 시작합니다.
- **새로 시작**: 배치 이름 · 벽 형태 · 크기 · 비밀번호를 정하면 바로 MongoDB 에 만들어지고,
  그다음부터는 고칠 때마다 **2초 뒤 자동 저장**됩니다 (Ctrl+S: 바로 저장).
- **불러오기**: 저장된 모든 배치의 이름 목록이 보이고, 누르면 비밀번호를 물어봅니다.
  한 번 맞게 입력하면 이 브라우저가 기억해서 다음부터는 묻지 않습니다 (🔓 표시).
- 비밀번호는 서버에 scrypt 해시로만 저장되며 찾을 수 없습니다. 10번 연속 틀리면 10분 동안 잠깁니다.
- 다른 사람이 먼저 저장했으면 덮어쓸지, 그 사람의 버전을 불러올지 물어봅니다.
- [저장·인쇄] 탭에서 링크 복사, 복사본으로 저장, 비밀번호 바꾸기, 클라우드에서 삭제를 할 수 있습니다.
- 다시 접속하면 마지막으로 작업하던 배치가 이어서 열립니다.
- 업로드 이미지는 배치와 따로 한 장씩 저장합니다 (Vercel 요청 4.5MB 제한, MongoDB 문서 16MB 제한 대응).

### 처음 한 번 설정

1. **MongoDB Atlas** (https://cloud.mongodb.com) 에서 무료(M0) 클러스터를 만듭니다.
   - Database Access: DB 사용자(아이디/비밀번호) 추가
   - Network Access: `0.0.0.0/0` 허용 (Vercel 서버 IP가 고정되어 있지 않기 때문)
   - Connect → Drivers 에서 접속 문자열(`mongodb+srv://…`) 복사
2. **Vercel** (https://vercel.com) → Add New Project → 이 GitHub 저장소 선택
   - Framework Preset: **Other**, Build Command·Output Directory 는 비워 둠
   - Environment Variables:
     - `MONGODB_URI` = 1번에서 복사한 접속 문자열 (비밀번호 부분을 실제 값으로)
     - `MONGODB_DB` = `booth_simulator` (선택)
   - Deploy → 발급된 `https://….vercel.app` 주소로 접속
3. 구글 사이트에는 Vercel 주소를 **삽입 → URL로 삽입** 하세요.

> 앱 화면만 GitHub Pages 에 두고 API 는 Vercel 을 쓰려면, `index.html` 의
> `<meta name="booth-api" content="">` 에 Vercel 주소(예: `https://my-booth.vercel.app`)를 넣으세요.
> 파일을 더블클릭해 연 경우(file://)에는 이 주소를 넣지 않으면 클라우드 저장 버튼이 숨겨집니다.

### 로컬에서 실행해 보기

```bash
npm install
cp .env.example .env      # MONGODB_URI 입력
npm run dev               # http://localhost:3000
```

MongoDB 없이 화면만 시험하려면 `npm run dev:memory` (메모리 DB, 서버를 끄면 데이터가 사라짐).

### API

| 요청 | 설명 |
| --- | --- |
| `POST /api/layouts` | 새 배치 `{ title, password, data, assetIds }` → `{ id, version, missing }` |
| `GET /api/layouts` | 배치 목록 (이름·요약·수정 시각만) |
| `GET /api/layouts/:id` | 배치 불러오기 (헤더 `X-Booth-Password`, 403 틀림 / 429 잠김) |
| `PUT /api/layouts/:id` | 덮어쓰기 `{ password, title, data, assetIds, baseVersion, force? }` → 403 비밀번호 틀림 / 409 버전 충돌 |
| `DELETE /api/layouts/:id` | 삭제 `{ password }` |
| `POST /api/assets` | 이미지 1장 `{ layoutId, password, assetId, data }` |
| `GET /api/assets?layout=…&id=…` | 이미지 1장 (dataURL, 헤더 `X-Booth-Password`) |

MongoDB 컬렉션: `layouts` (배치, 이미지 제외), `assets` (이미지, `layoutId` 인덱스).

## 주요 기능

- **3D 보기**: 드래그 회전, 휠/핀치 확대, 오른쪽 드래그/두 손가락 이동. 글씨가 읽힐 만큼 가까이부터 전시장 전체까지 확대·축소
- **시점**: 정면 · 좌측 · 우측 · 평면도(정사영) · 조감 · 관람객 눈높이 150cm (W/A/S/D·화살표로 걷기), 선택 물체로 **포커스**
- **바닥 격자** 10/50/100cm, **치수선**(부스 폭×깊이×높이, 선택 물체 가로×깊이×높이) 켜고 끄기
- **부스**: 폭·깊이·벽 높이·벽 두께·바닥/벽 색, 벽마다 켜기/끄기와 길이·높이 개별 설정, 옆 부스 경계선·통로 폭 표시
- **전시 작품**: 지류 작품(A5~A0·4절·8절·사진, 세워 놓기/눕히기/액자), 책(덮은 책/펼친 책/북스탠드), 아크릴 스탠드,
  입체 도형(정육면체·구·원기둥·원뿔·사각뿔·고리), 도자기, 투명 케이스, 리플릿 꽂이, 명패, 화분 — 작품·표지 이미지 올리기
- **디지털**: 태블릿 PC, 스탠드형 TV(43~86인치), 노트북·모니터(화면 이미지), 단말 자리, 키오스크
- **현수막**: 이름·가로·세로·벽(앞/뒤/좌/우)·하단 높이로 생성, 벽 위 드래그(모서리·다른 현수막에 스냅, 벽 밖 금지), 겹치면 빨간 경고
  - **칸 분할** N열×M행, 칸마다 이미지(PNG/JPG/PDF 첫 페이지, 맞춤/채우기/늘이기) · 텍스트(제목·본문·글자 높이·색·배경·정렬) · 단색 · 빈 칸
  - 텍스처는 긴 변 2048px 이상, 비등방성 필터 최대
- **자유 패널**: 롤업 배너, X배너, 입간판, 이젤 위 작품, 받침발 패널 — 바닥에 세움
- **집기 라이브러리**: 직사각 테이블(180×60, 180×45, 120×60 대여 규격), 정사각/원형 테이블, 의자·스툴, 진열 선반, 낮은 전시 단, 좌대, 상자, 노트북·모니터·단말 자리·키오스크, 사람 실루엣 160/175cm
  - 가로·깊이·높이·색 수정, 이름 붙이기, 회전(15° 단위/자유 입력), 그리드 스냅(1/5/10cm)
  - 겹치거나 부스 밖으로 나가면 빨간색 (의자는 테이블 아래로 넣을 수 있음)
  - 노트북·모니터·상자는 테이블/선반/전시단 위에 놓으면 높이가 자동으로 올라가고, 테이블을 옮기면 함께 움직임
- **목록(레이어)**: 이름 클릭 선택, 더블클릭 포커스, 🔒 잠금, 👁 숨김
- **저장**: 클라우드(MongoDB) 저장·공유 링크, 브라우저 자동 저장(localStorage), JSON 내보내기/불러오기(업로드 이미지 포함)
- **내보내기**: 3D 스크린샷 PNG, **평면도 + 벽면 입면도** PNG/PDF(A3, 번호·규격·설치 위치 표기), 물품 목록 CSV(엑셀용)

## 파일 구조

```
index.html        화면 뼈대, three.js(CDN importmap) 로드 후 앱 시작
css/style.css     반응형 스타일 (태블릿/모바일에서는 패널이 서랍처럼 열림)
js/core.js        공용 유틸 · 상태 모델 · 기본값 · 실행취소
js/scene.js       렌더러 · 카메라 · 조명 · 격자 · 치수선 · 시점 · 걷기 모드
js/booth.js       부스 바닥 · 벽 · 통로 · 옆 부스 경계, 벽 좌표계
js/panels.js      현수막/자유 패널: 칸 분할 캔버스 텍스처, 벽 스냅, 겹침 검사
js/items.js       집기 라이브러리 · 모델 · 충돌 검사 · 자동 적층
js/interaction.js 클릭 선택 · 드래그 · 키보드 단축키
js/storage.js     자동 저장 · JSON · 스크린샷 · 평면도/입면도 · CSV · 이미지/PDF 업로드
js/ui.js          설정 패널(부스/추가/선택/목록/파일) · 툴바 · 처음 설정 창
js/app.js         앱 초기화 · 변경 반영 · 선택 · 추가/삭제/복제/회전 · 데모 장면
js/cloud.js       클라우드 저장 · 공유 링크 · 편집 비밀번호 · 버전 충돌 처리
api/              Vercel 서버리스 함수 (layouts, assets)
lib/              API 공용: MongoDB 연결(db.js), 저장 로직(layouts.js), HTTP 헬퍼, 시험용 메모리 DB
dev-server.js     로컬 개발 서버 (npm run dev / npm run dev:memory)
```

`js/*.js` 는 ES 모듈이 아닌 일반 스크립트(전역 `BS` 네임스페이스)입니다.
브라우저는 `file://` 로 연 페이지에서 로컬 ES 모듈을 막기 때문에, 더블클릭 실행을 위해 이렇게 구성했습니다.
three.js 와 OrbitControls 만 CDN ES 모듈로 불러옵니다.

## 참고

- 단위는 모두 cm, 좌표 원점은 부스 바닥 중앙입니다. 화면·평면도에서는 "왼쪽 벽에서 / 뒷벽에서" 거리로 표시합니다.
- 벽 현수막 위치는 **부스 안쪽에서 벽을 바라볼 때** 기준(벽 왼쪽 끝→현수막 왼쪽 끝, 바닥→현수막 하단)입니다.
- 업로드 이미지는 긴 변 2400px 로 줄여 저장합니다. 이미지가 많아 브라우저 저장 용량(약 5MB)을 넘으면 자동 저장에서 이미지가 빠지므로 JSON 내보내기로 보관하세요.
- PDF 업로드(첫 페이지 변환)와 평면도 PDF 저장은 필요할 때 CDN에서 pdf.js / jsPDF 를 불러옵니다.
